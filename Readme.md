# Седона · Адаптивная вёрстка

Учебный многостраничный сайт туристического города, выполненный во время обучения в HTML Academy. Демонстрирует мою подготовку во фронтенде: HTML, адаптивные стили и интерактивное меню.

**HTML · SCSS · JavaScript · Gulp · BrowserSync**

[Портфолио автора](https://github.com/DuVla) · [Кекстаграм: JavaScript](https://github.com/DuVla/kekstagram-26)

## Что реализовано

- Главная страница, каталог фотографий и форма обратной связи.
- Адаптивные состояния для мобильных, планшетных и настольных экранов.
- Стили разделены на SCSS-модули компонентов.
- Открытие и закрытие мобильного меню на JavaScript.
- Сборка SCSS, Autoprefixer и локальный сервер с обновлением страницы через Gulp / BrowserSync.

Проект помогает показать понимание DOM, CSS-состояний, поведения форм и особенностей адаптивного интерфейса — это также полезно при тестировании веб-приложений.

## Локальный запуск

Исходная среда проекта указана в `package.json`: Node.js 16. Проект создан в 2022 году; совместимость с новыми версиями Node.js отдельно не проверялась.

```bash
npm ci
npm start
```

Адрес локального сервера появится в терминале. Для сборки только стилей:

```bash
npm run build
```

Для проверки оформления исходников:

```bash
npm run lint
```

## Где смотреть код

```text
source/
  index.html         # главная страница
  catalog.html       # фотокаталог
  form.html          # обратная связь
  sass/              # SCSS-компоненты и адаптивные стили
  js/script.js       # мобильное меню
  img/               # изображения и SVG
  fonts/             # шрифты
gulpfile.js          # стили, сервер и наблюдение за изменениями
```
